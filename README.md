One original single sentence about a small moment of wonder in everyday life — a shadow, usually the follower, arrives at the corner first and waits for its owner to catch up, turning the ordinary strange in a single read.

> My shadow reached the corner half a step before I did, then waited for me to catch up.

## Run

```sh
node main.ts
```

This writes the entry to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The program is deterministic: no network, no clock, no randomness. The entry is 86 characters, within the 200-character cap.
